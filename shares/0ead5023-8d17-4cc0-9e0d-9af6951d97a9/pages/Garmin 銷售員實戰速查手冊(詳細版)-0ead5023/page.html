銷售黃金對答邏輯 框架

開場必問三句
1. 你平時主要做咩運動多：跑步、健身、行山、單車、高爾夫、游水等
2. 你希望隻錶主要幫你解決咩問題：訓練進步、健康監測、續航、通知或外觀等
3. 你之前有冇用過運動錶或 Garmin：升級需求或第一次購買

需求對應表

| 顧客需求 | 推薦系列 | 一句話話術 |
|---|---|---|
| 想系統化跑步訓練 | Forerunner 系列 | 「有每日訓練建議與跑步動態，幫你科學化提升成績。」 |
| 想日常佩戴且螢幕漂亮 | Venu 系列 | 「AMOLED 螢幕靚、支援通話與音樂，日常與運動都好用。」 |
| 需要耐用與長續航 | Fenix 或 Instinct | 「軍規耐用加太陽能或超長續航，野外使用最安心。」 |
| 送禮或偏女性款 | Lily 或 Venu 3S | 「細巧設計與女性健康功能，外觀與實用兼備。」 |
| 打高爾夫 | Approach 系列 | 「預載球道圖與虛擬球童，打波更有策略。」 |
| 騎單車且重安全 | Edge + Varia | 「碼表導航加雷達尾燈，訓練與安全兼顧。」 |
| 預算有限但要功能 | Vivoactive 或 入門 Forerunner | 「性價比高，基本 GPS 與健康追蹤齊全。」 |

常見異議處理

| 異議 | 應對要點 |
|---|---|
| 太貴 | 強調「不是只買錶，是買教練、健康監測與耐用性」，以年均成本拆算降低阻力 |
| 功能太多用不到 | 提供「客製化設定」，只顯示常用功能，進階功能隨時可用 |
| 手機已經有 GPS | 解釋「手錶提供 24 小時心率與專業運動模式，佩戴更方便且防水」 |
| 電池要常充 | 依系列說明續航差異並推薦省電或太陽能款以符合需求 |
| 不知道選哪款 | 以「最重要功能」快速收窄選項（螢幕、續航、訓練或耐用） |

成交技巧與話術模板
- 上手體驗：請顧客試戴並示範 1–2 個關鍵功能（心率、Body Battery、地圖）
- 價值拆解：把價格拆成「每日成本」或「使用年限」來比較，降低價格阻力
- 免費資源：強調 Garmin Connect App 免費且有教練與數據分析功能，買錶只是開始
- 加購建議：推薦快拆表帶、保護貼、充電線、單車配件等提升客單價
- 限時或行貨保養：提醒香港行貨保養與更新服務，增加信任感

快速話術範例
- 「如果你最重視訓練分析，我會推 Forerunner；想日常又要靚螢幕就選 Venu；常去郊外就選 Fenix 或 Instinct。」
- 「這隻錶可以幫你記錄 24 小時心率與睡眠，長期看數據會發現生活習慣的改善空間。」
- 「你想我幫你先設定常用錶面與運動模式，試戴看看感覺如何？」

快速備忘
- 先問運動類型，再問佩戴場景，最後問預算與偏好
- 讓顧客上手體驗是最有效的成交動作
- 熟悉常見型號的續航、定位與差異，能快速建立專業感
